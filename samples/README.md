# Tenantry.Pro samples

Runnable samples for Tenantry.Pro 0.4.0 (on Tenantry Core 0.4.0), referenced from the
[documentation](https://tenantry.dev/docs/pro). They restore Tenantry.Pro from the private package feed, so
set up your credentials first: see [Installation](https://tenantry.dev/docs/pro/installation). Each sample
needs your own licence key as `Tenantry:Licence` (for example `dotnet user-secrets set "Tenantry:Licence" "<key>"`).
The samples contain no licence key or token: keep yours in user secrets and environment variables, never in
the files you commit.
